Standard Way to raise a PR(pull request)
 1.create feature branch i.e git checkout -b  <feature-branch-name>
 2.Used the source control to add the unstaged changes i.e git add . 
 3.Write Commit message for Staged Changes i.e git commit -m "message"
 4.Commit
 5.Publish your feature branch
 6.Raise PR
 7.Review Changes
 8.Merge Changes into base branch

Standard Method to Switch the branch
 1.commit your changes or stash them before you switch branches.
 2.stash = locally files ko save karna without commiting in feature branch i.e git stash
 3.Change the branch i.e git checkout <branch-name>
 4.locally files ko unsave karna in feature branch i.e git stash pop
