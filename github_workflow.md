Standard Way to raise a PR(pull request)
 1.create feature branch
 2.Used the source control to add the unstaged changes i.e git add . 
 3.Write Commit message for Staged Changes i.e git commit -m "message"
 4.Commit
 5.Publish your feature branch
 6.Raise PR
 7.Review Changes
 8.Merge Changes into base branch
